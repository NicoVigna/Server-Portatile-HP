# DuckDNS - componente archiviato

Il container DuckDNS non e piu utilizzato.

La connessione del server e dietro CGNAT TIM FWA, quindi l'aggiornamento di un
record DNS dinamico non permette di ricevere connessioni in ingresso. Il
`docker-compose.yml` e il file `.env.example` sono conservati esclusivamente
come riferimento storico e non fanno parte dello stack attivo.
